# 🎵 Mood Catcher

一个文艺风格的音符捕获小游戏，使用纯 HTML/CSS/JavaScript 构建。

## 🎮 游戏玩法

1. 点击 **Start** 按钮开始游戏
2. 使用 **Left** 和 **Right** 按钮控制平台移动
3. 或者使用键盘方向键 ← → 控制
4. 接住掉落的音符获得分数
5. 错过音符会扣分

## ✨ 特色

- 🎨 简约文艺的网格背景风格
- 🔔 10种不同的音乐符号
- 📱 响应式设计，支持移动端
- 🖱️ 支持鼠标和键盘操作

## 🚀 快速开始

### 方式一：直接打开

直接双击 `index.html` 文件在浏览器中打开即可游戏。

### 方式二：本地服务器

```bash
# 使用 Python 启动简单服务器
python -m http.server 8000

# 或使用 Node.js
npx serve .
```

然后访问 `http://localhost:8000`

## 🌐 部署到 GitHub Pages

1. 点击仓库的 **Settings**
2. 找到 **Pages** 选项
3. 在 **Source** 中选择：
   - **Branch**: `main`
   - **Folder**: `/ (root)`
4. 点击 **Save**
5. 等待几分钟，GitHub 会自动部署

部署完成后，你的游戏将在 `https://<你的用户名>.github.io/<仓库名>/` 访问。
